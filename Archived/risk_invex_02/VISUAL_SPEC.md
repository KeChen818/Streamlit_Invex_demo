# Visual Design Spec

## Style Name
Bloomberg Terminal-lite Enterprise Risk Dashboard

## Design Principles
1. Dense information layout
2. High contrast dark background
3. Yellow/amber as command/action color
4. Green/red for directional movement
5. Compact KPI cards
6. Minimal decorative elements
7. Charts and tables prioritized over text blocks

## Page Sections
1. Sidebar navigation
2. Executive header
3. Market/risk ticker row
4. KPI summary row
5. Risk heatmap
6. Risk category ranking
7. AI analyst insight panel
8. Emerging risk alerts
9. Latest risk changes table

## Color Palette
- Background: #050505
- Panel: #0b0b0b
- Border: #2b2b2b
- Text: #f5f5f5
- Muted: #9ca3af
- Amber: #f5a400
- Green: #22c55e
- Red: #ef4444
